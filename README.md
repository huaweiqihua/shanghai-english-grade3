# 上海小学3-4年级英语测试

基于沪版英语教材，适合三年级和四年级学生的英语拼写练习程序。

## 🎯 功能特点

- **拼写模式**：根据中文提示手动拼写英文单词
- **沪版教材词汇**：基于上海小学3-4年级英语教材
- **70+词汇题库**：涵盖问候、自我、家庭、数字、颜色、动物、食物、学校、身体、星期、科目、活动等
- **即时反馈**：提交后立即显示对错
- **成绩统计**：显示得分和详细答题情况

## 💻 本地运行

```bash
# 克隆仓库
git clone https://github.com/huaweiqihua/shanghai-english-grade3.git

# 进入目录
cd shanghai-english-grade3

# 用浏览器打开 index.html
# 或使用Python服务器
python -m http.server 8000

# 访问 http://localhost:8000
```
