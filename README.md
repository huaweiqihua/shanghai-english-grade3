# 上海小学三年级英语测试

一个简单有趣的英语测试程序，适合上海小学三年级学生。

## 🎯 功能特点

- **30道精选题目**：涵盖字母、颜色、数字、动物、食物、家庭成员、身体部位、日常对话等
- **随机抽题**：每次测试随机抽取10道题
- **互动界面**：可爱的图标和动画效果
- **即时反馈**：答题后立即显示对错
- **成绩统计**：测试结束后显示得分和详细答题情况

## 🚀 使用方法

直接在浏览器中打开 `index.html` 即可开始测试！

```bash
# 或者使用简单的HTTP服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 📝 测试内容

| 类别 | 示例 |
|------|------|
| 字母 | 大小写对应 |
| 颜色 | red, blue, green, yellow |
| 数字 | one, two, three, five, ten |
| 动物 | cat, dog, bird, fish |
| 食物 | apple, bread, milk |
| 家庭 | father, mother, brother |
| 身体 | eye, nose, mouth |
| 对话 | Hello, Thank you, Goodbye |
